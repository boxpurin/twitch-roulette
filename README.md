# Twitch Roulette

Twitch OAuth でログインし、指定したチャンネルポイント報酬を交換した視聴者をルーレットに登録する React / TypeScript / Vite のブラウザアプリです。バックエンドなしで動作します。手動での項目追加も可能です。

## ルーレットを回す

ログイン後、項目名を入力して「項目を追加」を押し、円盤直下の「ルーレットを回す」で抽選します。約4秒で減速して停止し、上部の矢印が指す当選項目を円盤下に表示します。

- 抽選対象が0件の場合（全項目を除外した場合も含む）と演出中は回すボタンが無効になります。
- 演出中は項目の追加・編集・削除・除外の切り替えも無効になります。停止後は再編集・再抽選できます。
- 当選確率は「本人の倍率 ÷ 抽選対象の倍率合計」です。倍率 1 と 3 の場合は 25% と 75%、全員 1 倍なら均等です。円盤の面積も同じ比率です。
- 項目の「編集」で名前と倍率を変更できます。倍率は 1 以上の安全な整数です。当選した項目を自動削除しません。
- 各項目の「抽選から除外」にチェックすると、名前・倍率・交換回数を残したまま抽選と円盤から除外できます。チェックを外すと復帰します。除外中に同じ視聴者が再交換しても倍率と交換回数は増えますが、除外は解除されません。
- 項目・交換回数・倍率・除外状態は localStorage に保存します。当選結果はメモリ内だけで保持します。
- Canvas 2D で円盤を描画し、回転中だけ描画フレームを予約します。停止・画面破棄時にはループを終了します。

## チャンネルポイント連携

手動追加でも Twitch アカウントを紐づけられます。「Twitch ログイン名（任意）」にプロフィール URL の `twitch.tv/` に続く名前を入力し、「ユーザーを確認」で表示名・画像・ID を確認してから追加してください。項目名が空欄なら取得した表示名を補完します。ログイン名が空欄なら従来どおり独立した手動項目になります。

紐づけた手動追加は倍率 1・交換 0 回で登録し、登録済みの同じ ID なら「倍率を +1」で現在の倍率だけを加算します。既存の名前・除外設定は維持します。その後に受信した同じユーザーの報酬交換も同じ項目へ加算します。手動追加は交換回数に含めません。紐づけと交換の合算は、現在選択している報酬の履歴内だけで行います。ユーザー検索には [Get Users API](https://dev.twitch.tv/docs/api/reference/#get-users) を既存の認証で利用し、追加権限は要求しません。

1. ログインすると配信者自身のカスタム報酬一覧を自動取得します。「対象報酬」のドロップダウンから報酬名を選び、「報酬を選択」を押します。必要ポイント数も表示されます。
2. 「受付を開始」を押し、「報酬交換を受信しています。」と表示されてから交換を受け付けます。報酬を変更する前に受付を停止してください。
3. 未登録の視聴者は初回の交換で倍率 1 の項目として登録します。同じ Twitch ユーザー ID の登録済み項目には、現在倍率へ 1 を加算します。手動追加・変更がなければ 2 回なら 2 倍、3 回なら 3 倍です。手動で 5 倍に変更した後の交換は 6 倍です。
4. 一覧で交換回数・倍率・当選確率を確認できます。同名でもユーザー ID が異なれば別項目になります。Twitch と紐づけていない手動項目は視聴者の項目と独立しています。
5. 回転中に届いた交換も保存します。抽選対象は回転開始時に固定し、到着分は回転終了後の一覧・次回抽選に反映します。

一覧は Twitch の [Get Custom Reward API](https://dev.twitch.tv/docs/api/reference/#get-custom-reward) から、既存の読み取り権限で取得します。Twitch 管理画面で作成した報酬も含みます。報酬 ID を調べる必要はありません。取得失敗・タイムアウトでは「報酬一覧を再取得」を押してください。報酬がない場合は Twitch 側でカスタム報酬を作成してから再取得します。

保存済みの報酬は一覧取得後に名前で表示されます。保存済みの報酬が削除されていても履歴は消さず、一覧に見つからない旨を表示します。その報酬での受付開始は無効になるため、別の報酬を選んでください。取得中や、受付中・回転中は報酬を切り替えられません。

EventSub WebSocket の welcome 後に、既存の `channel:read:redemptions` 権限で報酬交換イベントを購読します。同じ交換 ID・通知メッセージ ID は二重加算しません。keepalive のタイムアウト・通常切断後は再接続と再購読を行い、Twitch の再接続指示では購読を引き継ぎます。受付停止・ログアウトでは WebSocket と監視・再試行タイマーを終了します。WebSocket の切断に伴い Twitch 側の購読も無効化されます。

受付停止中・切断中の交換や、利用開始前の過去の交換を遡って取得しません。接続エラー・購読失敗・権限取消は画面に表示します。認証期限切れでは再ログインしてください。報酬交換のキャンセル・返金による倍率の減算は行いません。

## 当選者履歴

円盤下の「当選者履歴」でモーダルを開き、正常に完了した抽選の直近20件を確認できます。「回した日時」「名前」「当選回数」を表示し、表示順を新しい順（降順）・古い順（昇順）で切り替えられます。「閉じる」または Escape キーで閉じられます。

- 日時は回転開始時刻をブラウザの現地時刻で `yyyy/mm/dd hh:mm`（24時間表記）に整形します。名前は当選時点のものを残します。
- 各行の「○回目」は、現在の画面を開いてから数えた参加者ごとの累計当選回数です。Twitch参加者はユーザーID、手動項目は項目IDで識別します。同じ名前でも別のIDなら別集計です。
- 表示が20件を超えて古い記録が消えても累計回数は保持します。Twitch参加者は削除後に同じIDで再登録しても通算し、新しく作り直した手動項目は別IDのため1回目から数えます。
- 当選者履歴と累計当選回数は画面内のメモリで保持します。対象のチャンネルポイント報酬を切り替えても履歴は入れ替わらず、同じTwitchユーザーIDの当選回数も通算します。項目リセットでも残ります。
- 更新・別ページへの移動・戻る／進む操作・ログアウトなどで抽選画面を離れると、当選者履歴と累計当選回数をクリアします。ブラウザの戻る操作で画面が復元されても履歴は復元しません。
- 当選者履歴は localStorage / sessionStorage に保存しません。以前の版で保存された当選者履歴も読み込まず、参加者一覧などの保存データだけを引き継ぎます。

## 履歴の保存とリセット

- 項目・表示名・倍率・交換回数・重複排除に必要な ID を、配信者 ID と報酬 ID ごとに localStorage へ保存します。選択した報酬 ID も次回ログイン時に復元します。報酬未選択の手動項目には独立した保存先があります。
- 再読み込み・ログアウト後も参加者の登録履歴は残り、同じアカウントで再ログインすると復元します。アプリが実際に受信した交換のみ累積します。
- 「履歴をリセット」→「削除してリセット」で、現在の保存先の全項目（手動項目を含む）・交換回数・倍率・現在の当選結果を消去し、受付を停止します。当選者履歴と累計当選回数は残ります。確認の「キャンセル」では削除しません。回転中はリセットできません。
- リセット時刻以前の交換の再送は無視します。受付を再開した後の新しい交換から倍率 1 で再登録します。別報酬・別アカウントの履歴は消しません。
- 保存制限・容量不足・破損データは画面に表示します。保存できない場合もメモリ内で抽選できますが、変更が残るとは限りません。破損・未対応データは、明示的にリセットするまで上書きしません。
- 履歴はこのブラウザの同一オリジン内だけで保存され、サイトデータの削除で失われます。複数タブで同時に操作すると後の保存で上書きされるため、一画面で利用してください。別ブラウザ・端末・OBS ソースとの同期はありません。
- OAuth トークンは履歴に含めず、引き続きメモリだけで保持します。
